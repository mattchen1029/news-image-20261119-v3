A one-page newspaper front page for Thursday 19 November 2026: 46 stories across 7 regions, with three illustrated leads, a BY THE NUMBERS strip, a through-the-day UTC timeline, and a date check. Every story on the page happened, or was first reported, on that day.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` renders the front page with `render.py` (pure Python standard library, no network) and writes `entry.png` — byte-identical on every run.
